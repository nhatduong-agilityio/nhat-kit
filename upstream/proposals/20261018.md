## Scope

devkit is no longer a single-engineer kit. It already has a shared GitHub issue queue with multi-machine claims (P-20), plan ↔ tracker sync (P-25), and PR report artifacts. The user set the direction on 2026-10-18: grow it in two stages.

- **Stage 1: team on a shared queue.** Several engineers, or several Claude sessions, pull from one issue queue and each opens their own small PR. No orchestrating agent.
- **Stage 2: squad orchestration.** One session splits a SPEC or plan into tasks, runs developers in parallel in isolated worktrees, has each task reviewed and tested, and stops at stakeholder gates.

Stage 2 builds on stage 1 (claims, PR size, gates, result contracts), so stage 1 comes first.
